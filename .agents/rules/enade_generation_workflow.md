# Regra de Execução: Gerador de Questões ENADE

> [!IMPORTANT]
> **REGRA MANDATÓRIA DE INTERAÇÃO COM O USUÁRIO (NÃO PULAR ETAPAS DE PLANEJAMENTO)**

Sempre que o usuário solicitar a geração de questões no padrão ENADE (seja com ou sem arquivos PDF de UA), o agente **JAMAIS** deve gerar as questões ou criar documentos finais automaticamente sem antes realizar a consulta prévia dos seguintes parâmetros:

1. **Apresentar os Objetivos de Aprendizagem (OAs)** extraídos ou mapeados das UAs e solicitar a confirmação/seleção dos OAs que o usuário deseja focar.
2. **Solicitar a Quantidade de Questões** desejada no total ou por UA.
3. **Solicitar a Escolha dos Modelos Estruturais** de preferência do usuário (Múltipla Escolha Direta, Escolha Combinada I/II/III, Asserção-Razão PORQUE, ou Discursiva).

A geração de questões e a exportação para Word (.docx) só devem ser iniciadas **APÓS** a confirmação explícita do usuário para estes 3 itens.
